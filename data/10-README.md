# Data

This project uses the IBM Telco Customer Churn sample dataset:

- File: `WA_Fn-UseC_-Telco-Customer-Churn.csv` (7,043 rows, 21 columns)
- Widely mirrored, for example on Kaggle: search "Telco Customer Churn" by BlastChar.

The CSV is not re-uploaded to this repository because the redistribution licence for the
mirror sites is not explicit. Download it from one of the public mirrors instead.

`customers_clean.csv` (the cleaned table exported from MySQL after `02_cleaning.sql`) is
also kept out of the repository; it is derived from the same source and is only needed as
the input for the Power BI report.
